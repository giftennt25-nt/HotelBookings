# Hotel Room Booking — Coding Test
 by:  Giften N Thankachan

## How to Run
1. Download or clone the repository
2. Open `index.html` in any browser

## Stack Used
- Plain HTML5
- CSS3
- JavaScript

## Features 
- Displays list of hotel rooms with room code, type, price and max guests
- Check-in and Check-out date selection
- Date validation — check-out must be after check-in, check-in cannot be in the past
- Room selection
- Calculates number of nights and total price on button click
- Clear error messages for invalid input
- Filter rooms by max guests (Bonus)
- Hardcoded existing bookings to prevent double booking (Bonus)
- Rooms already booked for selected dates are marked and disabled
